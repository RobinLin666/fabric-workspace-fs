# Security policy

## Reporting a vulnerability

Please report security issues privately through this repository's GitHub
Security Advisories ("Report a vulnerability"). Do not open a public issue for
credentials, token handling problems, authorization bypasses, or data-loss
risks.

Include the affected version or commit, operating system, reproduction steps,
and the expected versus observed behavior. Do not include live access tokens,
client secrets, cookies, credential-cache files, or customer data.

## Supported versions

This project is under active development. Security fixes are provided on the
latest revision of the default branch.
